# Ejercicio 4 — Redacción de historias de usuario

## 1. Historias de usuario

**Historia usuario 1 — Socio**
> **Como** socio de la biblioteca,
> **quiero** consultar los libros que tengo prestados,
> **para** saber cuáles tengo que devolver.

**Historia usuario 2 — Bibliotecario**
> **Como** bibliotecario,
> **quiero** registrar la devolución de un libro,
> **para** que el ejemplar vuelva a estar disponible para otros socios.

**Historia usuario 3 — Administrador del sistema (primera versión)**
> **Como** administrador del sistema,
> **quiero** gestionar los socios,
> **para** tener el sistema organizado.

## 2. Comprobación INVEST

| Criterio | Hist. 1 | Hist. 2 | Hist. 3 (primera versión) |
|---|---|---|---|
| **I** - Independiente | Sí | Sí | Sí |
| **N** - Negociable | Sí | Sí | Sí |
| **V** - Valiosa | Sí: el socio sabe qué debe devolver | Sí: otros socios pueden volver a pedir el libro | Dudoso: "tener el sistema organizado" no es un beneficio concreto |
| **E** - Estimable | Sí | Sí | No: "gestionar" puede ser dar de alta, modificar, dar de baja... |
| **S** - Pequeña | Sí | Sí | No: incluye demasiadas funciones para un solo sprint |
| **T** - Testable | Sí | Sí | No: no se puede comprobar cuándo está "gestionado" |

**Historia usuario 3 — Administrador del sistema (reformulada)**
> **Como** administrador del sistema,
> **quiero** dar de baja a un socio,
> **para** que no pueda solicitar nuevos préstamos.

Ahora sí es valiosa, estimable, es una funcionalidad pequeña y testable: se puede comprobar si un socio dado de baja puede o no pedir un préstamo. El resto de acciones que implican "gestionar" serían otras historias distintas.

## 3. Criterios de aceptación de Historia Usuario 2

**Historia:** Como bibliotecario, quiero registrar la devolución de un libro, para que el ejemplar vuelva a estar disponible para otros socios.

**Criterio 1: devolución correcta**
- **DADO** que el libro "El nombre del viento" tiene 1 ejemplar disponible y el socio con número 7 tiene un ejemplar prestado
- **CUANDO** el bibliotecario registra la devolución del socio 7
- **ENTONCES** el libro pasa a tener 2 ejemplares disponibles y el préstamo se marca como finalizado

**Criterio 2: libro no prestado a ese socio**
- **DADO** que el socio 7 no tiene prestado "El nombre del viento"
- **CUANDO** el bibliotecario intenta registrar una devolución de "El nombre del viento" para el socio 7
- **ENTONCES** el sistema muestra un aviso y los ejemplares disponibles no cambian

**Criterio 3: préstamo ya devuelto**
- **DADO** que el préstamo del socio 7 ya está finalizado
- **CUANDO** el bibliotecario intenta registrar otra vez su devolución
- **ENTONCES** el sistema muestra un aviso y los ejemplares disponibles no cambian
